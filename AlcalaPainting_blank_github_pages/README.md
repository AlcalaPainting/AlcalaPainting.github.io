# AlcalaPainting.github.io

Minimal starter repository for the Alcala Painting GitHub Pages website.

## Publish

1. In GitHub, open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. After GitHub Pages finishes deploying, visit https://AlcalaPainting.github.io.
